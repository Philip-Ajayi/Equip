### 1. Color Palette & Material Architecture
* **Ibadan Earthen Terracotta (`#5925dc`)**: Primary brand accent; used for interactive focal points, active states, key data highlights, and 3D surface material highlights. Symbolizes the red earth of Oyo State and foundational shaping.
* **Deep Nigerian Ink (`#0a0f1d`)**: Deep neutral background for high-contrast sections; text primary on light backgrounds.
* **Raw Linen Canvas (`#f8f9fc`)**: Global body surface color. Warm, tactile, non-glare editorial background that reduces eye strain and establishes warmth.
* **Ancient Slate (`#212832`)**: Secondary dark surface; card backgrounds in dark sections; borders and subtle divider lines.
* **Hebron Ochre Gold (`#D99B26`)**: Faith-informed purpose accent; badge indicators, financial goal progress fills, and leadership highlights.
* **UI Emerald Verification (`#1C7C54`)**: Trust and transparency badge color; used in the accountability policy and budget balance checkouts.

### 2. Typography Strategy
* **Editorial Display Serif**: `Fraunces` (Google Font variable font, Optical Size 9–144, Weights 400–800) or `Instrument Serif`. Expresses dignity, moral gravity, and institutional credibility.
  * H1 Hero: `text-5xl md:text-7xl lg:text-8xl font-normal tracking-tight leading-[1.05]`
  * H2 Section Headers: `text-3xl md:text-5xl font-normal tracking-tight leading-[1.15]`
  * H3 Feature Headers: `text-xl md:text-2xl font-medium tracking-normal`
* **Structural Grotesque Sans**: `Geist Sans` or `Plus Jakarta Sans` (Weights 400, 500, 600, 700). High-legibility UI typography engineered for dense dashboards, track listings, and narrative body copy.
  * Body Text: `text-base md:text-lg text-white/80 leading-relaxed font-normal`
  * Captions & Overlines: `text-xs md:text-sm font-semibold tracking-wider uppercase text-[#5925dc]`
* **Technical Monospace**: `Geist Mono` or `JetBrains Mono`. Financial figures, timetable timestamps, GPS coordinates for Hebron Center, and budget lines.
  * Ledger Lines: `font-mono text-sm tracking-tight`

### 3. Motion System & Spring Choreography
* **Motion Engine**: Motion for React (`motion/react`).
* **Global Spring Preset**: `const springSmooth = { type: "spring", stiffness: 120, damping: 20, mass: 0.8 };`
* **Scroll-Linked Parallax**: Utilizes `useScroll` and `useTransform` with clamped output ranges to prevent GPU thread locking.
* **Reduced Motion Compliance**:
  ```tsx
  // lib/motion.ts
  import { useReducedMotion } from "motion/react";
  export function useAccessibleAnimation() {
    const shouldReduceMotion = useReducedMotion();
    return {
      fadeUp: {
        initial: shouldReduceMotion ? { opacity: 1 } : { opacity: 0, y: 24 },
        animate: { opacity: 1, y: 0 },
        transition: { duration: shouldReduceMotion ? 0 : 0.6, ease: [0.16, 1, 0.3, 1] }
      }
    };
  }
  ```

### 4. 3D WebGL Monolith Specification (React Three Fiber)
* **Mesh Definition**: Procedurally generated asymmetrical dodecahedron / sculpted faceted obelisk geometry with chamfered vertices.
* **Material Properties**: Custom `MeshStandardMaterial` layered with a procedural noise normal map simulating weathered terracotta rock and metallic gold veining:
  - `roughness`: 0.72
  - `metalness`: 0.18
  - `color`: `#5925dc`
  - `bumpScale`: 0.05
* **Lighting Rig**:
  - Key Light: Warm directional light (`#FFF5EB`, intensity: 1.8) at `[5, 8, 5]`.
  - Fill Light: Cool ambient skylight (`#B0C4DE`, intensity: 0.6) at `[-5, -2, -2]`.
  - Rim Light: Ochre accent light (`#D99B26`, intensity: 2.2) at `[0, -5, -5]`.
* **Interaction Loop**: The mesh subtly tracks cursor movement in viewport coordinates via linear interpolation (`lerp` factor: 0.05). On scroll, the monolith rotates 360 degrees around the Y-axis across the height of the document, translating smoothly along the X-axis to avoid obscuring typographic layouts.

### Risk Mitigation & Contingency Matrix
1. **WebGL Thermal Throttling on Low-End Mobile Devices**:
   - *Risk*: Android devices running low-power GPUs experience frame stuttering on continuous R3F render loops.
   - *Mitigation*: The `GlobalScene` component interrogates `navigator.hardwareConcurrency` and WebGL context limits. On devices with `< 4GB RAM` or explicit mobile user agents, real-time 3D rendering is bypassed in favor of a CSS 3D matrix transform displaying pre-rendered, high-resolution WebP views of the monolith. Zero performance penalty.
2. **Layout Shift during Route Navigation**:
   - *Risk*: Soft-page transitions in Next.js App Router causing jarring content jumps while the 3D camera orbits.
   - *Mitigation*: Content containers use fixed min-height wrappers (`min-h-[calc(100vh-5rem)]`) and enter/exit opacity transitions managed by Motion for React with exit animations completed before scroll restoration.
3. **Delayed Verification of Training Track Texts**:
   - *Risk*: Stakeholders deliver the final 2-sentence strings for the 11 skills late in Month 2.
   - *Mitigation*: The `data/curriculum.ts` file isolates content completely from the UI layer. The UI is built and tested against typed schema interfaces (`SkillItem { id: string; name: string; focus: string; expectedResult: string; }`), allowing instant string replacement without touching UI logic.
