I’ll structure this as a complete, copy-ready Next.js project, with every file shown individually as full source code rather than a ZIP or download. The design will follow your MINDSHIFT blueprint: warm linen backgrounds, terracotta accents, editorial serif typography, refined cards, responsive layouts, subtle motion, and a distinctive sculptural hero.

A few important decisions will keep the project usable:

- Visuals first: no backend, payment processing, or real application submission services.
- Complete navigation: home, initiative, programs, EQUIP, training, schedule, facilitators, impact, funding, registration, and contact.
- Honest content: names, biographies, official social links, and banking information that you haven't supplied will remain clearly marked placeholders rather than invented facts.
- Working interactions: mobile navigation, curriculum tabs, accordions, budget calculations, and demonstration forms will work in the browser.
- Responsive performance: the sculptural hero will have a lightweight fallback rather than forcing every device to run a heavy 3D scene.
- Your existing assets: I’ll reference the images in `public/images/` and provide graceful fallbacks when an image is missing.

One detail matters for the financial page: your brief specifies a total of ₦8,450,000, but doesn't provide the seven individual budget amounts. I'll use a clearly labeled illustrative allocation that adds up to the exact total, so you can replace it with your approved figures.

## File 15 — `components/reveal.tsx`

This provides optional motion for sections. Reduced-motion preferences are respected, and the page remains readable if JavaScript animation is unavailable.

```

"use client";

import { motion, useReducedMotion } from "motion/react";
import type { ReactNode } from "react";

export default function Reveal({
  children,
  delay = 0,
  className,
}: {
  children: ReactNode;
  delay?: number;
  className?: string;
}) {
  const reduceMotion = useReducedMotion();

  return (
    <motion.div
      className={className}
      initial={
        reduceMotion ? { opacity: 1 } : { opacity: 0, y: 20 }
      }
      whileInView={{ opacity: 1, y: 0 }}
      viewport={{ once: true, amount: 0.12 }}
      transition={{
        duration: reduceMotion ? 0 : 0.6,
        delay: reduceMotion ? 0 : delay,
        ease: [0.16, 1, 0.3, 1],
      }}
    >
      {children}
    </motion.div>
  );
}
```

```
  age: "",

  school: "",

  statement: "",
};

  "Your details",
  "Education",
  "Choose a track",
  "Review",
];

  const [step, setStep] = useState(0);
  const [form, setForm] = useState(initialForm);
  const [completed, setCompleted] = useState(false);

  function update<K extends keyof StudentForm>(
    key: K,
    value: StudentForm[K],
  ) {
    setForm((current) => ({ ...current, [key]: value }));
  }

  function validateCurrentStep() {
    if (step === 0) {
      return (
        form.fullName.trim().length > 1 &&
        /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(form.email) &&
        form.phone.trim().length >= 7 &&
        Number(form.age) >= 13
      );
    }

    if (step === 1) {
      return Boolean(form.state && form.lga.trim() && form.school.trim());
    }

    if (step === 2) {
      return Boolean(form.track);
    }

    return form.statement.trim().length >= 20;
  }

    if (!validateCurrentStep()) {
      window.alert(
        "Please complete the required fields before continuing.",
      );
      return;

      setStep((current) => current + 1);
    } else {
      setCompleted(true);

    setStep((current) => Math.max(0, current - 1));
```
